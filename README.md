# ⚽ 축구선수로 다시 태어나기

지구에서 공을 차는 사람 2억 6천만 명 중 한 명으로 무작위로 다시 태어납니다. 대부분은 조기축구로 끝납니다. 원래 그렇습니다.

- 국적 143개국(축구 인구 가중) · 포지션 · 주발 · 키 · 별명 · 이상한 소속팀 · 시그니처 기술 · 은퇴 후 · 같은 해 동기 비교
- 이번 생 최고 도달점 8단계: 취미 축구인 → 등록 아마추어 → 하부리그 프로 → 1부리그 프로 → 국가대표 → 5대 리그 → 월드컵 → 발롱도르
- 결과는 폰 한 화면 카드로 뜹니다. 캡처해서 자랑하거나 억울해하세요.

숫자는 FIFA Big Count(2006) 등을 자릿수 수준으로 어림한 값입니다. 통계가 아니라 장난감입니다.
